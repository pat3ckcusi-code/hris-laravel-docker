# Dashboard Modules

## Employee Dashboard
- View leave history
- File new leave request
- View balances
- Request cancellations
- Export PDS
- Document request history

## Department Head Dashboard
- Pending request badge
- Approve leave/ETA/locator
- Department statistics
- Monthly usage chart
- On-duty status
- Travel/office orders

## Administrative Officer Dashboard
- Similar to Dept Head
- Exclude own requests
- Pre-approval printing workflow
- Deduction preview
- Revert deductions on rejection

## HR Manager Dashboard
- Workforce analytics
- Employee records CRUD
- Leave management
- Document tracking
- Audit log viewer
- System settings
- Export reports
- Role assignment

## Mayor Dashboard
- City-wide overview
- Approve dept head/HR manager leaves
- Travel order approvals
- Analytics/reports
- Employee directory
- Policies/events

## Records Manager Dashboard
- Employee master data
- Department management
- Access level distribution
- Employee type distribution
- Data quality metrics

## Leave Manager Dashboard
- Manage balances
- Apply credits/deductions
- Cancel leave dates
- Approve/reject cancellations
- Holiday auto-cancel
- Balance summary

## Front Desk Dashboard
- Document workflow
- Filter requests
- Status emails
- Print documents
- Generate reports
